# Strict Scope & Preservation of Existing Features

## Directives
1. **Strict Scope**: When the user requests a task, only execute the exact requested task. Do not make unrelated changes or add unrequested features.
2. **Preserve Existing Functionality**: All existing features, endpoints, and UI elements across Admin, HR, Employee, Finance, Realtime, and Google Sheet integration must remain intact and functional.
3. **No Regression**: All existing automated tests must continue to pass 100%.
